# Pizzeria Jetski Web App & VMs

A full-stack web application and virtualized infrastructure project for the Pizzeria Jetski system.

## Project Overview

This repository contains the application, database-related components, virtual machine infrastructure, automation scripts, tests, and technical documentation of the Pizzeria Jetski project.

## Main Components

- Backend — NestJS
- Frontend — Web application
- Database — PostgreSQL
- Infrastructure — Virtual machines and network configuration
- Documentation — Architecture, API, database, infrastructure, and development documentation
